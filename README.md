# Borrowboard · 邻里借用

上架 → 借出通过 → 归还（归还前预演确认）；单物件同时仅一笔在借，含逾期判定（逾期 = 应还日 + 宽限日之后，宽限日在设置页可配，0 或正整数）。

逾期判定全站同一套：看板分栏、顶细条计数、借还记录、归还预演都按设置页当前宽限。改宽限与归还确认撞在同一秒时，归还提交若带着旧宽限版本会被拒（409 grace_changed），重新预演确认即可；非法宽限整单失败，不落库。
